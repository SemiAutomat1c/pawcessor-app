macOS desktop pet

Pawcessor

A pixel cat that lives on the desktop, works when your agent works, and stays out of the way while you type.

Download for Mac

macOS 14 or later. Universal zip, about 4 MB.

Mac only for now. Want a Windows version? Let me know.

First launch

  1. Unzip Pawcessor-macos.zip and drag Pawcessor.app into Applications.
  2. Control-click the app and choose Open. Confirm Open if macOS asks.
  3. If you still see “Not Opened”, go to System Settings, Privacy & Security, then Open Anyway.

This preview is ad-hoc signed, not notarized. Apple has not checked it. A notarized build comes later.

What you see

Local only

No accounts, no analytics, no internet sockets. It never asks for Accessibility, Input Monitoring, Screen Recording, camera, or microphone.

Optional Orca support reads one private status file on your Mac. Prompts and code stay unread. Connect Codex from the pawprint inspector if you want Codex full-state; trust the hook in Codex with /hooks. VS Code, Cursor, Claude, and Antigravity are presence only.

Click the cat to pet it. Feed, pause, hide, preview poses, and reset are on right-click. The pawprint extra shows care stats, Connect Codex, and display. After Hide, use show on the inspector.

Pawcessor is a menu-bar accessory. No Dock icon. Skipping a meal only softens Mood. The pet cannot die, get sick, or run away.
